# API RESTful - Gestión de Contactos

Proyecto de la tarea HT-04 (SENATI) para la empresa "Atención Total".

**Tecnologías:** Node.js, Express, MySQL, Sequelize y Docker.

**Funcionalidades (CRUD):**
* Listar contactos (GET)
* Crear contacto (POST)
* Editar contacto (PUT)
* Eliminar contacto (DELETE)
